# 1회 응시 제한 및 예외 허용(재응시) 로직 구현 계획

기본적으로 1명의 원장님이 1회만 응시할 수 있도록 제한하되, 예외 상황 발생 시 어드민에서 재응시 권한을 부여할 수 있는 기능을 구현합니다. (이 문서는 작업 완료 시 `docs/` 폴더로 복사되어 저장됩니다.)

## 구현 목표
1. 사용자가 이미 시험을 본 경우 로그인 화면에서 차단 (1회 응시 제한)
2. 어드민 페이지에서 특정 사용자(이메일)에게 재응시 권한 부여 기능 추가
3. 재응시 권한이 부여된 사용자는 새롭게 시험 응시 및 데이터 누적 가능

---

## 작업 내용 (아론이 모두 구현합니다!)

### 1. [프론트엔드] `src/pages/admin/AdminDashboard.jsx` (NEW)
- 특정 원장님의 이메일을 입력하고 **"재응시 권한 부여"** 버튼을 누를 수 있는 UI 추가
- 클릭 시 구글 시트 백엔드로 `action='allow_retake'` POST 요청 전송

### 2. [프론트엔드] `src/App.jsx` (MODIFY)
- 새로 만든 `AdminDashboard` 컴포넌트를 import 하도록 라우터 연결 수정

### 3. [프론트엔드] `src/hooks/useAuth.js` & `src/pages/ExamAuth.jsx` (MODIFY)
- `verify_owner` 요청 시 백엔드에서 내려주는 에러 메시지(`ALREADY_SUBMITTED`)를 캐치하여 "이미 평가를 완료하셨습니다. 재응시가 필요한 경우 본사로 문의해 주세요." 텍스트 노출

### 4. [백엔드] 구글 앱스 스크립트 (GAS) 코드 작성 (NEW)
- 제이슨님이 구글 시트 스크립트 편집기에 **그대로 복사/붙여넣기만 하시면 되도록** 완벽한 `.gs` 코드를 작성해 드립니다.
- 포함될 로직:
  - `allow_retake` (재응시 권한) 열(Column) 읽기/쓰기 기능
  - `verify_owner` 시 응시 이력 및 재응시 권한 검사 (차단 기능)
  - `allow_retake` 액션 시 권한을 `TRUE`로 변경하는 기능
  - `submit_exam` 완료 시 권한을 다시 `FALSE`로 회수하는 기능

---

계획을 확인하시고 **[진행(Proceed)]** 버튼을 눌러주시면 바로 프론트엔드 코드 작성 및 GAS 스크립트 제작을 시작하겠습니다!
