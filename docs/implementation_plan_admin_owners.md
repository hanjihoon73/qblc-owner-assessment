# [Phase 5] 어드민 내 '원장 관리(추가)' 기능 구현 계획서

관리자(어드민) 시스템 내에서 원장님(응시자) 정보를 새로 등록하고 관리할 수 있는 기능을 추가합니다. 구글 시트의 `owners` 탭과 연동됩니다.

## 💡 User Review Required
> **[중요] 기획 및 UI/UX 확인 요청**
> 1. 원장 정보를 추가할 때 기본적으로 입력받아야 할 항목은 **`이메일`, `이름`, `센터(가맹점)명`** 3가지로 구성하면 될까요? (`id`는 시스템이 자동 부여, `재응시 허용 여부`와 `배정 세트`는 나중에 수정 가능하도록 할 수 있습니다.)
> 2. "원장 관리"라는 새로운 탭(화면)을 만들어, 현재 등록된 원장님들의 목록을 보여주고 우측 상단에 **[+ 새 원장 등록]** 버튼을 배치하는 일반적인 방식으로 구현해도 괜찮으신가요?

## 🛠 Proposed Changes

### 1. 백엔드 (Google Apps Script - `docs/gas_update_guide_admin.md`)

#### [MODIFY] `docs/gas_update_guide_admin.md`
- **`doGet` 함수 수정:** `action === "get_owners"` 블록 추가
  - 프론트엔드에 `owners` 시트의 전체 원장 리스트를 반환하는 API 기능 추가.
- **`doPost` 함수 수정:** `action === "add_owner"` 블록 추가
  - 프론트엔드에서 받은 새로운 원장 데이터(이메일, 이름, 가맹점 등)를 `owners` 시트의 맨 아랫줄에 추가.
- **`doPost` 함수 수정:** `action === "edit_owner"`, `delete_owner` 블록 추가 (추후 관리를 위한 대비)

### 2. 프론트엔드 라우팅 및 레이아웃 수정

#### [MODIFY] `src/App.jsx`
- `/admin/owners` 경로에 대한 라우팅 보호 및 컴포넌트 매핑 추가.

#### [MODIFY] `src/pages/admin/AdminLayout.jsx`
- 상단 네비게이션 탭(`navItems`)에 **'원장 관리'** 메뉴 추가.

### 3. 신규 프론트엔드 화면 구현

#### [NEW] `src/pages/admin/AdminOwners.jsx`
- **역할:** 원장 관리 메인 화면.
- **기능:** 등록된 전체 원장님들의 리스트(테이블 형태)를 띄워주고, [+ 새 원장 등록] 버튼 제공.
- 데이터를 백엔드 API(`get_owners`)에서 불러와 상태(`useState`)로 관리.

#### [NEW] `src/components/admin/OwnerManager.jsx`
- **역할:** 원장 추가/수정 시 나타나는 팝업(모달) 컴포넌트.
- **기능:** 
  - 필수 입력값: 이메일, 이름, 센터명.
  - 선택 입력값: 기본 배정 세트(A/B).
  - 저장 시 백엔드 API(`add_owner`) 호출하여 데이터 갱신.
