# 어드민 시스템 및 평가 세트 관리 최종 구축 계획서

제이슨님의 기획안(`qblc-owner-assessment-planning.md`)과 답변 내용을 꼼꼼히 확인하여, **전체 응시자 기본 세트 지정 + 예외적 개별 세트 지정 + 3단계 루브릭 기반 서술형 채점(64점 합격)** 기능을 모두 포함하는 최종 계획서입니다.

## 🎯 핵심 기능 및 목표
1. **평가 세트 및 문항 관리 (`/admin/questions`)**
   - 평가 세트별 문항 조회, 추가, 수정, 삭제(CRUD)
2. **응시 세트 배정 로직 (글로벌 + 개별 옵션)**
   - 기본적으로 어드민에서 지정한 '현재 활성 세트(예: Set A)'가 모든 원장님께 공통 배정
   - 예외적으로 특정 원장님에게만 다른 세트(예: Set B)를 지정하는 옵션 기능 추가
3. **서술형 수동 채점 및 자동 합격 판정 (`/admin/grade/:id`)**
   - 3단계 루브릭(1~3점) 적용 서술형 채점 UI 구현
   - 채점 완료 시 객관식(48점) + OX(8점) + 서술형(24점) 총합 계산
   - **64점(80%) 이상 득점 시 자동 '합격' 판정**
4. **응시자 현황 대시보드 (`/admin`)**
   - 전체 응시 현황, 배정된 세트, 취득 점수 확인 및 재응시 허용 관리

## 📂 폴더 구조 및 파일 구성 계획

```text
src/
 ┣ pages/
 ┃ ┗ admin/
 ┃    ┣ AdminLayout.jsx      (어드민 전용 레이아웃)
 ┃    ┣ AdminDashboard.jsx   (응시 내역 목록 및 권한/개별세트 관리)
 ┃    ┣ AdminGrade.jsx       (답안 상세 보기 및 루브릭 기반 채점 화면)
 ┃    ┗ AdminQuestions.jsx   (평가 세트 및 문항 관리 화면)
 ┣ components/
 ┃ ┗ admin/
 ┃    ┣ SubmissionTable.jsx  (응시 내역 표 컴포넌트)
 ┃    ┣ GradingForm.jsx      (문항별 1~3점 입력 및 총점 계산 컴포넌트)
 ┃    ┗ QuestionManager.jsx  (문항 추가/수정/삭제 폼 컴포넌트)
```

## 개발 완료 사항
위 모든 기능은 React 컴포넌트 및 GAS 스크립트 기반으로 완전히 개발되었습니다.
