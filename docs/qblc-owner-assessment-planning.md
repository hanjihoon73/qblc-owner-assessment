## 1. 개요

### 1.1 목적

깨봉수학 러닝센터(QBLC) 가맹 원장의 교육 역량을 평가하는 웹 기반 시험 시스템. 원장이 깨봉수학의 교육 철학, 커리큘럼, 운영 정책, LMS 사용법, 학부모 상담 역량을 갖추었는지 확인하고, 합격 여부를 판정한다.

### 1.2 배경

* 대상: QBLC 가맹 원장 (프랜차이즈 오너)
* 운영 주체: 깨봉수학 본사 마케팅 그룹

### 1.3 핵심 요구사항 요약

* 원장이 웹 폼에서 40문항을 응시하고 제출
* 선다형/OX는 자동 채점, 서술형은 관리자가 수동 채점
* 총점과 합격 여부 자동 산출
* 관리자 대시보드에서 응시 현황 조회 및 서술형 채점

## 5. 채점 로직

### 5.1 자동 채점 (선다 + OX)

```
선다 점수 = Σ(Q가 정답이면 1, 아니면 0) × 2  // 24문항, 만점 48
OX 점수   = Σ(Q가 정답이면 1, 아니면 0) × 1  // 8문항, 만점 8
```

### 5.2 수동 채점 (서술형)

관리자가 각 서술형 문항에 3단계 루브릭으로 점수 부여:

| 등급 | 점수 | 기준                              |
| -- | -- | ------------------------------- |
| 우수 | 3  | 핵심 개념을 정확히 서술 + 구체적 예시 또는 근거 제시 |
| 보통 | 2  | 방향은 맞으나 핵심 개념 일부 누락 또는 부정확      |
| 부족 | 1  | 무응답 또는 관련 없는 내용 서술              |

```
서술형 점수 = Σ(8문항 루브릭 점수)  // 각 1~3점, 만점 24
```

### 5.3 총점 및 합격 판정

```
총점 = 선다 점수 + OX 점수 + 서술형 점수   // 만점 80
합격여부 = 총점 ≥ 64 ? "합격" : "불합격"   // 80점의 80%
```

## 7. 화면 구성

### 7.1 응시자 화면

#### 7.1.1 응시 인증 페이지 (`/exam`)

* 이메일 입력 필드
* DB에 등록된 원장 이메일과 일치 시 → 시험 페이지로 진입
* 미등록 이메일 → "등록되지 않은 이메일입니다" 안내

#### 7.1.2 시험 응시 페이지 (`/exam/:id`)

* 상단: 응시자 정보(이메일 인증으로 자동 표시) + 잔여 시간 타이머 (90분)
* 본문: 5개 섹션으로 구분된 40문항 폼
  * 각 섹션에 섹션명 + 영역 표시
  * 선다형: 라디오 버튼 (①②③④)
  * OX형: 라디오 버튼 (O / X)
  * 서술형: textarea
* 하단: 제출 버튼
* 미답 문항 경고 (제출 시 확인)
* 시간 초과 시 작성 내용 자동 제출
* 제출 후 → 결과 페이지로 이동

#### 7.1.3 결과 확인 페이지 (`/result/:id`)

* 자동 채점 결과 즉시 표시 (선다 점수, OX 점수)
* 서술형 미채점 시 "채점 중" 안내
* 채점 완료 시 총점 + 합격/불합격 표시

### 7.2 관리자 화면

#### 7.2.1 응시 현황 대시보드 (`/admin`)

* 응시 목록 테이블: 응시자명, 센터명, 응시일, 선다 점수, OX 점수, 서술형 점수, 총점, 합격여부
* 정렬: 응시일 내림차순
* 필터: 합격여부, 센터명
* 상태 필터: 전체 / 채점 완료 / 채점 대기

#### 7.2.2 서술형 채점 페이지 (`/admin/grade/:id`)

* 응시자 정보 표시
* 서술형 8문항의 답안 + 루브릭 점수 선택 (우수 3 / 보통 2 / 부족 1)
* 각 문항별 출제 의도/채점 기준 가이드 표시 (옵션)
* 저장 시 → 서술형 환산, 총점, 합격여부 자동 재계산

## 부록 A: 깨봉수학 교육 체계 참조

시험 문항이 다루는 깨봉수학 핵심 개념:

* **교수법 3원리**: 시각화, 스토리텔링, 수학적 사고
* **수학적 사고 3역량**: 추상화(무시), 구조화(패턴), 변화 감지
* **코칭 3단계**: 관찰 → 질문 → 피드백
* **커리큘럼 구조**: CORE (A\~E) → ADVANCED → ADVANCED-E → ELITE
* **깨봉 7가지 수학적 사고**: 왜왜왜, 쉽고 아는것으로, 보이게하라, 무시하라, 변화를 꺼내라, 관계를 맺어라, 분해하고 융합하라
* **수학을 망치는 방법**: 기계적 계산, 무작정 공식 외우기, 유형별 요령 외우기, 1차원적 사고
