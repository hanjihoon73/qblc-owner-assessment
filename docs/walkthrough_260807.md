# 문항 관리 어드민 및 채점 시스템 백엔드 이관 완료

프론트엔드에 하드코딩 되어있던 문항(Questions)을 구글 시트로 완전히 분리하고, 정답 유출을 막기 위해 모든 채점 로직을 구글 시트 앱스 스크립트(백엔드)로 이관하는 대대적인 작업을 성공적으로 완료했습니다! 🎉

## 주요 변경 사항

### 1. 엑셀 기반 어드민 기능 확보 (`questions` 시트)
- 더 이상 코드 수정을 위해 개발자에게 의존할 필요가 없습니다.
- 원장님이 구글 시트의 **`questions` 탭**에서 직접 문제 지문, 선택지 1~4번, 배점, 그리고 **정답**까지 마치 엑셀을 다루듯 손쉽게 수정하고 추가할 수 있습니다.

### 2. 채점 로직 백엔드 이관 (보안 강화)
- 기존에는 프론트엔드가 정답지 전체를 다운로드 받아 클라이언트에서 채점하는 방식이었습니다. (해킹/부정행위 위험)
- 이제 프론트엔드는 응시자가 선택한 **'답안'**만 서버로 던집니다.
- 구글 스크립트 내부에서 시트의 정답과 대조하여 **직접 채점**을 수행한 뒤 점수만 내려주도록 완벽하게 보안을 강화했습니다.

### 3. 문항 데이터 동적 로딩
- 사용자가 시험 페이지(ExamForm)에 진입하면, 로딩 스피너가 돌면서 구글 시트로부터 실시간 문항 데이터를 가져옵니다.
- 이 때 정답(`answer`) 데이터는 프론트엔드로 절대 넘어오지 않습니다.

## 🚀 다음 스텝 가이드 (원장님 필수 진행 사항)

로직이 완전히 바뀌었기 때문에, 변경된 방식에 맞게 구글 시트를 다시 세팅해 주셔야 합니다! (약 2분 소요)

1. **GAS 코드 복사 & 붙여넣기**
   - 로컬 `docs/google_apps_script.js` 파일의 전체 내용을 복사하여 **구글 앱스 스크립트 에디터**에 붙여넣고 저장(Ctrl+S)해 주세요.
2. **시트 세팅 함수 실행**
   - 구글 에디터 상단의 함수 선택 메뉴에서 **`setupSheetHeaders`**를 선택하고 **[▷ 실행]**을 누릅니다.
   - (실행되면 기존의 `answer_key` 시트는 삭제되고, 완벽하게 구조가 잡힌 새로운 **`questions` 시트**가 생성됩니다.)
3. **새로운 배포 승인 (매우 중요 ⭐)**
   - 코드가 크게 바뀌었으므로 기존 URL로는 동작하지 않습니다. 반드시 **[새 배포]**를 진행해 주셔야 합니다.
   - 우측 상단 **[배포] -> [새 배포]** 클릭
   - 설명을 `v2 - 문항 어드민 및 백엔드 채점` 등으로 적고 **[배포]** 클릭
   - 새로 생성된 **웹앱 URL을 복사**하여, 로컬 프로젝트의 `.env` 파일에 있는 `VITE_GAS_API_URL` 값에 덮어씌워 줍니다. (이후 서버 재시작 필요)
4. **문항 데이터 복사 & 붙여넣기**
   - 로컬 폴더에 제가 엑셀용으로 새로 만들어둔 **`docs/questions_upload.tsv`** 파일을 열어 전체(Ctrl+A) 복사(Ctrl+C) 합니다.
   - 구글 시트의 **`questions` 탭 A1 셀**을 클릭하고 그대로 붙여넣기(Ctrl+V) 합니다. (총 40개의 문항과 정답이 예쁘게 들어갑니다!)

모든 세팅이 끝나셨다면, 웹앱을 다시 띄워서 로딩 스피너와 함께 문제들이 잘 뜨는지, 그리고 아무거나 골라서 제출했을 때 구글 시트에 점수가 제대로 채점되어 들어가는지 테스트해 주세요!
